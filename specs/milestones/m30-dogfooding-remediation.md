# M30 — dogfooding remediation

0.2.1 vs 6 real repos, 24 runs: 16 done (3 WRONG), 4 killed >35min, 4 browser-error deaths. Every contract anchored to an observed failure.

- **F1 configFile:false** — harness must NEVER load the target's vite.config. Project pinning a newer Vite ships plugins for that major: @vitejs/plugin-react v6 (rolldown) inside our Vite 6 → HTTP 500 `Missing field 'moduleType'` for every module, surfacing only as a bare readiness timeout (3 repos); also inherits side effects (server.open). Partial adoption (aliases yes, plugins no) REJECTED — configs are executable, aliases can come from plugins. Residual risk accepted: project-only transforms (svgr/MDX/vanilla-extract) lost; surveyed repos need only tailwind+react, both harness-supplied. Aliases stay tsconfig-paths + shim table.
- **F2 elementTemplate** — arrays synthesized from element type (string→"text", union→first member, object→record over own props; recursion depth-capped 3, never follows a type into itself); unresolvable → old string fill. Observed: `AnnotatedLine[]` (discriminated union) got ["item-1"] → nothing rendered → DOM stuck at 9 for N=1..50 → reported "constant" growth + PASS on a component never exercised.
- **F2b domFlat** — identical domNodeCount at every point (>1 point) → domFlat:true + SCALING_NO_EFFECT_WARNING; verdict UNCHANGED (canvas/virtualized legitimately flat). Disclosure, not failure. Independent of F2 — a correct template isn't guaranteed.
- **F3 composition trial-mount** — structural inference picked list template for Select (SelectGroup matches List before SelectItem matches Item), buildListBased discards items when a trigger exists → empty #root + context throw; 48.9ms mount was measured against NOTHING. Fix: trial-mount composed scene once before calibration (reuse open page); 0 elements or throw → rebuild WITHOUT composition + COMPOSITION_EMPTY_WARNING pointing at --fixture; rolled-back scene sets no autoComposition. Taxonomy NOT reordered — item-first equally wrong for Select and risks working Tabs/Accordion/Dialog.
- **F4 explore run budget** — totalWallClockMs 300s + maxCombos 8 (was: per-combo 60s only; 27-combo colorpickers ran >35min). selectExploreCombos = first, last, evenly spaced interior; finish the running combo; skipped combos DISCLOSED via EXPLORE_BUDGET_WARNING (silent truncation reads as "no interactions"). Bounds exploration only — combo count still multiplies mount/rerender passes (own milestone).
- **F5 per-step interaction budgets** — median/steps vs interactionMs/REFERENCE_STEPS(11). 11 = rapid-toggle-11's step count, the pattern existing budgets were tuned against — behavior unchanged there BY CONSTRUCTION; single-shot stops being unbudgeted (1 click vs 350ms), pointer-drag (60 steps) stops failing for step count. Aggregate median stays in JSON/table; table shows steps so numbers reconcile.
- **F6 context-loss retry** — withContextRetry: re-enter + retry EXACTLY once (second loss = real failure); RetryBudget 2 per pass shared across samples — unbounded retries measured 3→7 e2e contention failures (re-navigation under load starves sibling tests). `Tracing.tracingComplete timed out` NOT retryable — session stays wedged ("Tracing has already been started"), needs a fresh CDP session; classifying retryable just converts a clear timeout into a protocol error. collectTrace does best-effort Tracing.end on action failure without masking the original error. explore protects 3 sites (initial mount+discovery costliest — loses a whole combo). Consumed retry → CONTEXT_RETRY_WARNING, deduped. `server.waitForRequestsIdle()` after listen(): tried, measured, REVERTED — 1→17 e2e failures (blocks startup while siblings hammer shared .vite cache).
- **F7** target repos: gitignore harness dirs + reports; don't bump their 120fps dep until published.

Open: domNodeCount counts whole document (~8-element baseline; empty scene reports dom 9) — fixing shifts every tier + invalidates baselines, needs fingerprint bump + own milestone. Run time still scales with combo count (capping measured combos changes combos/matrix/deltas/baseline shape). trnscrpt content-sections.tsx still hits tracingComplete timeout (trace genuinely never completes). REFERENCE_STEPS=11 preserves calibration but isn't frame-budget-derived — principled version = 16.7ms × throttle per step, needs dogfooding measurement.
