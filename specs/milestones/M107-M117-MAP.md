## Goal

A developer who points `120fps` at a component in a monorepo they did not build (workspace siblings
without `dist/`, Node `#imports`, tsconfig `references`, `jsx: preserve`, Tailwind 3 in a member
package) reaches a report or a refusal that names the real layer, from any directory. The dry run
predicts the real run. Every remedy names a file, flag or command that exists in that repository and
does what it says. A run prints where its minutes went, pays for each import-graph walk and each
explore replay once, and repeats no warning. Nothing is left behind, even on a signal.
